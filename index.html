Privacy Policy

KeyTrail is a native macOS menu bar app. From the menu bar you can look up and search keyboard shortcuts, see recent shortcuts that matched the built-in catalog, and keep your own shortcut records.

What this page describes

This page describes the KeyTrail app that runs on your Mac. KeyTrail does not have an account.

What the app handles

KeyTrail does not include advertising, analytics, crash reporting, or a network client. The app’s sandbox entitlement does not include a network client. The shortcut catalog is part of the app. KeyTrail does not send shortcut history, custom shortcuts, key events, or your language choice to the developer or to any other service.

Input Monitoring

Listening stays off until you choose “Start Listening”.

“Start Listening” is how KeyTrail notices built-in catalog shortcuts while another app is in front. If macOS has not already allowed Input Monitoring, that button asks for it once during that launch. If the permission is not available, listening does not start. You can still search and read the catalog, edit custom shortcuts, and read or clear history that is already saved.

“Input Monitoring Settings” opens System Settings to the Input Monitoring pane. You can allow or remove KeyTrail there. If you change this permission, quit KeyTrail and open it again. Listening stays off until you choose “Start Listening” again.

While listening is on, KeyTrail installs a listen-only event tap for key-down events. The tap returns each event unchanged. It does not block or rewrite the key.

For a key-down that is not a repeat, KeyTrail reads the key code and modifier keys in memory and compares them with the built-in catalog.

  • If nothing in the catalog matches, KeyTrail does not save that key-down.
  • If something matches, KeyTrail saves the catalog shortcut identifiers, the time, and the name and bundle identifier of the frontmost app. The saved history record does not include the key code.

“Pause Recording” stops new history from being written. If listening is still on, the tap can still receive key-down events. “Stop Listening” removes the tap.

This page does not claim that keys typed in a password field are ignored. The listener does not check secure input separately. While listening is on, key-down events are received so they can be compared with the catalog. Only a catalog match is saved.

Shortcut history

History is stored in a file named history.json, in the app’s sandbox Application Support folder. Each saved event has an identifier, the time, the matching catalog shortcut identifiers, the frontmost app’s name and bundle identifier, and a marker that the event came from a detected shortcut. The file keeps at most 200 events.

“Clear History” replaces that file with an empty list and writes the cleared list to history-recovery.json. That recovery file keeps only the most recent clear. “Restore cleared history” can put it back only while the current history is empty. Another clear replaces the recovery file. The app has no control that deletes a single history event.

Custom shortcuts

A custom shortcut is a record you keep. It does not register a system hotkey.

Recording does not use Input Monitoring. While “Record Shortcut” is on, KeyTrail watches key-down events inside its own window. If you save, the app stores the steps, including the key code and modifier keys, the category name, any details you entered, a version range, and the created and modified times, in custom-shortcuts.json in the same folder. The file also keeps the last category name and version range used in the editor.

You can delete a custom shortcut in the app. If that file cannot be read, the app moves it aside in the same folder, under a new name, so a later save does not overwrite it. A moved file stays on this Mac until you remove it.

Language

Until you choose a language, KeyTrail uses English. Your choice is stored in the app’s preferences on this Mac. KeyTrail does not upload it.

Sharing

KeyTrail does not sell or share this information. It does not use a third-party analytics, advertising, or crash-reporting service. The only system location the app opens is the Input Monitoring pane in System Settings.

How long information stays

KeyTrail does not delete history after a set number of days. It keeps up to 200 history events until you clear them. The recovery file keeps the last cleared list until you restore it or clear again. Custom shortcut records, and a file moved aside because it could not be read, remain until you delete them or remove the app’s data. Removing the app removes the sandbox container macOS keeps for it, including these files and the saved language preference.
